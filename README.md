# ShopNest

ShopNest is a full-stack e-commerce web application built using Node.js, Express.js, MongoDB, and EJS.

## Features

- User registration and login
- JWT-based authentication
- Product browsing
- Shopping cart
- Product management
- Order management
- Admin dashboard
- Product reviews
- Payment integration
- Session and flash message handling

## Tech Stack

### Frontend
- HTML
- CSS
- JavaScript
- EJS

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- Express Session
